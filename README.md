Parser

&#x20; &#x20;

Парсинг сайтов OLX.uz,UZUM,Yandex Market

Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/Yoko-ship/parser.git
cd repository

# Установка зависимостей
pip install requirements.txt

# Запуск проекта
py parsing.py
```

- 🟢 Python
- 🎨 Selenium
- 🖼️ CustomTkinter
